# 评测报告

评测分三层：**检索质量**（有没有找到对的依据）、**接口与流程**（单元测试）、**真实交互**（端到端）。
单元与端到端用例不依赖外部 API；线上演示另接了 DeepSeek（Key 仅存于服务端环境变量）。

---

## 1. 检索评测（RAG）

用例位于 `tests/evaluation/cases.json`，执行：

```bash
npx tsx scripts/evaluate-rag.ts
```

覆盖五类风险：地区差异、时间有效性、跨事项隔离、无证据拒答、地方/全国兜底。

| 用例 | 问题 | 地区 | 事项 | 返回条数 | 结果 |
|---|---|---|---|---|---|
| Q1 | 父亲居民医保缴费，地区北京，2026 年 | 北京市 | 社保缴纳 | 6 | 通过 |
| Q2 | 上海居民医保怎么参保 | 上海市 | 社保缴纳 | 6 | 通过 |
| Q3 | 异地就医备案怎么办 | 广东省 | 社保缴纳 | 6 | 通过 |
| Q4 | 新生儿医保参保 | 未知地区 | 社保缴纳 | 6 | 通过 |
| Q5 | 孩子上大学，想申请国家助学金 | 北京市 | 高校助学金 | 6 | 通过 |
| Q6 | 生源地助学贷款需要什么 | 河南省 | 高校助学金 | 6 | 通过 |
| Q7 | 老人高龄津贴怎么申请 | 上海市 | 老年与残障 | 6 | 通过 |
| Q8 | 重度残疾人护理补贴 | 四川省 | 老年与残障 | 6 | 通过 |
| Q9 | 医保报销（事项传成学生资助） | 北京市 | 高校助学金 | 6 | 通过 |
| Q10 | 2025 年居民医保缴费（已过期口径） | 北京市 | 社保缴纳 | 0 | 通过 |

**通过率 10/10。** 判定标准：

- 命中条目必须属于请求事项，跨事项结果为 0；
- 地区有地方条目时优先地方，同时保留全国兜底；
- 无有效期/已过期条目不得混入；
- 无适用证据时返回空数组，前端必须走“无法确认”分支。

## 4. 性能采样

```bash
npm run build && npm run start &     # 或 docker compose up -d
PERF_BASE_URL=http://127.0.0.1:3000 npm run test:performance
```

脚本并发 4、共 20 次“创建任务 → 检索 → 出解答”，输出 `test-results/performance.json`（median / p95 / max）。
该数据只反映**本地规则模式**下的接口与检索开销，不含模型调用与 OCR 耗时，不作为线上 SLA。

## 5. 已知评测缺口

1. 政策库为 63 条摘要，未覆盖全国所有地市；地方口径差异只能提示“以当地为准”。
2. OCR 只在少量中英文样本上验证，复杂版式（多栏、表格、手写）识别率会下降。
3. 六问与步骤的“可理解性”目前靠人工走查，尚未做目标用户可用性测试。
4. 模型轨道与规则轨道的一致性只做了抽样对比，没有系统评测集。
