# 阶段 7：联调、测试与演示部署

范围：现有规则驱动演示，不扩称真实 LLM、OCR 或向量 RAG。

执行顺序：
1. 修复首页至工作台的输入交接、追问参数、刷新恢复及网络错误反馈。
2. 加入匿名会话隔离；确认与页面读取必须属于当前会话。
3. 生产模式浏览器测试：创建、追问、证据、文件元数据、确认、家属清单、设置持久化及失败重试。
4. 验证无证据、跨地区、无权限、非法输入、并发和响应时间。
5. 增加 standalone Docker、健康检查、CI、手动触发的 GHCR 发布工作流与部署说明。

实现选择：
- 单进程匿名演示会话使用 HttpOnly / SameSite=Lax cookie，HTTPS 下 Secure。
- 会话与任务存在内存，服务重启即失效；不使用多实例或无服务器平台。
- 所有结果仍为演示指引，确认不等同于正式提交。文件只检查元数据。
- 网络请求有 15 秒超时，可在原输入上重试；测试用例模拟离线及超时。
- 不推送源码或自动发布。目标服务器、域名、平台凭据未知，实际公网部署须如实记录为未验证。

本阶段不引入注册账号；演示用户通过匿名会话进入，无需演示账号密码。
