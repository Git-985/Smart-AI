# 最终验收清单

## 功能闭环

- [x] `/demo` 三类场景直达工作台并带入描述（桌面/移动端 E2E 验证）
- [x] 需求输入、追问、证据、材料检查、知情确认和家属清单
- [x] 内置 30 条政策摘要，三场景各 10 条，含官方来源链接
- [x] 地方/全国政策检索与地区、年份、事项过滤
- [x] 任务、会话归属、审计写入 SQLite，服务重启后任务可恢复
- [x] `/admin/policies` 政策库新增/删除
- [x] 办理指南打印/导出 PDF

## 证据与安全

- [x] 缺少事项信息时先追问
- [x] 跨地区不混入其他地区证据，地方无匹配时返回全国摘要并提示核对
- [x] 无证据时不下确定结论
- [x] 任务内容脱敏、匿名会话隔离
- [x] 任务工作台的材料检查只读取类型和大小
- [x] `/documents` 文档解析只读取文本，不保存文件
- [x] 用户确认不代表正式提交
- [x] 政策库写操作支持 `ADMIN_TOKEN` 保护

## AI、RAG 与文档解析

- [x] DeepSeek 调用层（结构化 JSON、8 秒超时、规则回退）已实现
- [x] DeepSeek 真实 key 目标环境实测（事项识别、摘要、PII 脱敏）
- [x] 30 条三场景政策库与 SQLite 检索
- [x] RAG 10/10 评测通过（事项、地区、时间、跨事项不混检、拒答）
- [x] PDF / DOCX / TXT 文本提取
- [x] PNG/JPG/WEBP 图片 OCR（Tesseract.js 中文+英文，实测置信度 93%）
- [ ] 扫描版 PDF 逐页渲染 OCR（当前转为图片处理）
- [ ] 政策摘要由业务人员逐条复核

- [x] 语音不可用时保留文字路径
- [x] 家属协助清单

- [ ] 真实 iOS/Android 与 Edge 专项验收
