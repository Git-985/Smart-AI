# Smart AI 最终演示脚本

建议时长：6 分钟。演示使用虚构人物、演示地区和模拟政策条款。

## 0:00-0:30 背景

展示老人面对公共服务通知，不知道要准备什么、去哪里办、是否会办错。
说明 Smart AI 解决“看不懂、不会办、怕办错”三个问题。

## 0:30-1:00 进入产品

打开 `/demo`，选择“居民医保缴费咨询”。展示匿名进入、无障碍设置和
“不要上传真实证件”的提示。

## 1:00-2:00 需求输入与追问

在任务工作台展示已填入的虚拟场景。系统先识别事项；地区和年份缺失时先
追问，不直接下政策结论。可演示语音输入；浏览器不支持时改用文字。

## 2:00-3:00 Agent 工作流

补充“演示地区”和“2026”，点击继续梳理。沿任务时间线说明：
理解需求、补充信息、检索政策、检查材料、人工确认。说明每一步都有状态，
并且确认不会提交正式申请。

## 3:00-4:00 证据链与无证据兜底

展示政策名称、条款、地区、有效时间和适用理由。明确该条款为虚构演示数据。
更换地区再次检索，展示无适用证据时拒绝给出确定性结论。

## 4:00-5:00 材料、安全与无障碍

选择 PNG/JPG/PDF，说明只检查浏览器提供的文件类型和大小，不发送文件内容，
未执行 OCR。展示手机号/身份证号脱敏、大字体、高对比度和语音播报。

## 5:00-5:30 家属协助

进入家属协助清单，勾选步骤并刷新，展示仅保存在当前浏览器的状态。

## 5:30-6:00 架构与价值

展示 `architecture.md`。总结：可控任务流、证据边界、无障碍交互和人工确认
共同降低公共服务的数字门槛。说明当前为演示实现，真实模型、政策库、OCR、
数据库及正式提交需后续接入和重新验收。
