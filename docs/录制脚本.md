# Smart AI 功能演示录制脚本（5:50，无解说版）

> **内部使用，不是评委材料。** 本文件是给参赛者边看边操作的录制手册；视频完成后请删除本文件，并从 README 移除链接。
>
> 目标时长：**5:40–5:56**。画面：1920×1080，浏览器 100% 缩放。  
> 本版**不写问候、自我介绍或“今天演示”之类的解说**；屏幕上只显示功能标签，让人直接看操作和结果。

---

## 一、录制前准备

### 1. 启动

双击项目根目录的 `start.bat`，等浏览器打开 `http://localhost:3000`。  
如果要展示 DeepSeek，先确认 `.env` 已配置 `DEEPSEEK_API_KEY`；页面出现“DeepSeek 解析”标签才算生效。

### 2. 浏览器

- Edge 或 Chrome，窗口最大化，缩放 **100%**。
- `Ctrl + Shift + B` 隐藏书签栏。
- 关闭微信、QQ、系统通知；手机静音。
- 准备 4 个标签页：

| 标签 | 地址 | 用途 |
|---|---|---|
| Tab 1 | `http://localhost:3000/` | 主流程 |
| Tab 2 | 预先建好的“上海无证据”任务 | fail-closed 演示 |
| Tab 3 | `http://localhost:3000/documents` | 文档解析 |
| Tab 4 | `http://localhost:3000/onboarding` | 无障碍 |

**Tab 2 先建好：**

1. 打开 `http://localhost:3000/task/new`。
2. 描述输入：`居民医保缴费`。
3. 点“识别事项”。
4. 地区填：`上海市`；年份填：`2026`。
5. 点“继续梳理”。
6. 看到“没有找到适用的政策证据”后，**不要关闭、不要刷新**。

### 3. 准备两个材料

- `演示材料.png`：任务工作台“材料格式检查”用；仓库自带 `docs/assets/演示材料.png`，复制到桌面。
- `演示材料.pdf`：文档解析页用；可以用任意 PDF，建议放桌面，文件名改成 `演示材料.pdf`。

### 4. 录屏

- `Win + Alt + R`（Xbox Game Bar）或 OBS；1080p、30fps、MP4。
- 光标可见，移动慢一点。
- 先不录，完整走一遍，确认等待时间。

## 三、逐段操作细节

### 0:00–0:22 首页

1. 停在首页，鼠标不要点。
2. 向下滚动约半屏，露出三类服务卡片，停 1 秒，再回顶部。
3. 不念介绍；让画面自己说明。

### 0:22–0:40 演示入口

1. 点顶部“演示体验”。
2. 停 1 秒，让三类场景卡入镜。
3. 点“居民医保缴费咨询”。

### 0:40–1:20 识别、追问、证据

1. 点“识别事项”。
2. 等页面出现“所在省、市、区 / 办理年份”，并出现“DeepSeek 解析”标签和摘要。
3. 地区输入：`演示地区`。
4. 年份输入：`2026`。
5. 点“继续梳理”，等右侧证据卡。
6. 鼠标依次指：政策名称、地区、有效期、条款、来源、适用理由；最后指“演示政策、虚构样例”。

### 1:20–2:28 材料与确认

1. 点“材料格式检查”，选桌面的 `演示材料.png`。
2. 指右侧“材料信息已检查 / image/png / 未执行 OCR”。
3. 向下滚右侧面板，勾选“我已了解上述演示范围”。
4. 点“确认并记录”。
5. 等按钮变成“已记录确认”，出现“查看演示指南”。

### 2:28–3:16 指南与家属

1. 点“查看演示指南”。
2. 停 1 秒，让“现在该做什么”三条入镜。
3. 滚到底部，点“家属协助清单”。
4. 勾选前两项，底部出现“2 / 4 项已勾选”。

### 3:16–3:52 无证据兜底

1. 按 `Ctrl + 2` 切到 Tab 2（上海任务）。
2. 点“重新检查任务”。
3. 等中间出现“没有找到适用的政策证据，因此不提供确定性结论”。
4. 鼠标指中间提示，再指右侧没有证据卡的面板，停 2 秒。

### 3:52–4:34 文档解析

1. 按 `Ctrl + 3` 切到 `/documents`。
2. 选 `演示材料.pdf`，点“解析文档”。
3. 等“解析结果”出现。
4. 指文件名、`application/pdf`、`1 页`、`提取 53 字`、文本预览。
5. 不要展示真实证件或含个人信息的 PDF。

### 4:34–5:00 无障碍

1. 按 `Ctrl + 4` 切到 `/onboarding`。
2. 点“175%”，勾“高对比度”，停 2 秒。
3. 点回“100%”，取消“高对比度”。
4. 按 `Ctrl + 1` 回 Tab 1，点“← 返回首页”（如果页面不在顶部，先按 `Home`）。

### 5:00–5:50 架构与结尾

1. 停在首页，不要滚动。
2. 画面字幕依次显示：技术栈、测试与 CI、DeepSeek 可选、OCR 未启用、单进程限制。
3. 最后切结尾卡，停 5 秒。
