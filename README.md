# Smart AI（明白办）

面向老年人、残障人士和低数字素养人群的无障碍公共服务办理引导平台。首期范围为城乡居民医保、高校学生资助、老年与残障人士公共服务材料办理。

## 当前阶段

第一阶段完成基础工程与主要目录框架；第 3 至第 6 阶段已具备演示闭环：事项识别与追问、演示证据检索、浏览器语音交互、文件元数据检查、敏感信息脱敏、风险确认与审计、无障碍偏好及家属协助清单。当前不连接真实模型、不接收文件内容、不提供未经核实的政策结论。

## 本地启动

需要 Node.js 20.9 或更高版本、npm，以及 Docker（仅在需要本地数据库时）。

```bash
npm install
Copy-Item .env.example .env
npm run dev
```

访问 `http://localhost:3000`。数据库可选启动：

```bash
docker compose up -d postgres
npm run db:generate
npm run db:push
```

首次接入真实 AI 或存储前，请先配置 `.env`；不要将密钥、真实证件或上传文件提交到仓库。

## 主要路由

- `/` 产品首页与任务入口
- `/onboarding` 无障碍偏好入口
- `/task/new` 创建任务
- `/task/[id]` 任务工作台
- `/documents` 材料检查
- `/result/[id]` 办理指南
- `/family/[id]` 家属协助模式
- `/admin/policies` 政策资料管理入口
- `/demo` 虚拟演示入口

## 目录概览

```text
app/                 页面与 API 路由
components/          可复用界面组件
lib/ai/              结构化分析、提示词、Agent 状态流
lib/rag/             政策证据类型与检索入口
lib/security/        PII 脱敏、风险规则、审计辅助
prisma/              业务数据模型
scripts/             数据导入和演示数据脚本入口
tests/               自动化测试
```

## 开发约束

- 只用虚拟人物做演示，不上传真实证件。
- 政策回答必须绑定可验证来源；无证据时不下结论。
- 医疗、费用、资格权益和正式提交必须经过人工确认。
- `main` 只合并经过检查的功能分支；提交使用 `feat:`、`fix:`、`docs:` 等前缀。

## 已完成的阶段

- 阶段 3：创建任务、事项识别、地区和年份追问、Agent 状态、风险确认。
- 阶段 4：带地区、有效期、来源和适用理由的政策证据对象；无证据时 fail-closed。
- 阶段 5：材料格式/大小检查、质量字段演示、原文件不保存、语音输入和播报降级。
- 阶段 6：手机号/身份证号脱敏、API 输入限制、演示边界确认和最小审计记录；大字体、高对比度、语音引导偏好及家属协助清单。

材料检查当前只校验浏览器传来的文件类型和大小元数据，不会上传文件本身，也不执行 OCR 或真实质量评分。无障碍设置和家属清单仅保存在本机浏览器。
